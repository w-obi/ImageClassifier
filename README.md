# ImageClassifier

## About

### Description

**The purpose of this project was to learn the image processing and machine learning models like CNN and SVM on python**.

### Tools & Libraries
1. Anaconda
2. keras
3. sklearn
4. opencv
5. numpy

### Repository Structure

1. imgPrep.py: contains functions for preprocessing images.
2. SVM.ipynb
3. CNN.ipynb

## Setup Project

### Prerequisites
Make sure that the following tools are already installed:
- Python: Programming language used for machine learning.
- Pip: The standard package manager for Python
- Git: It is an open source version control system.
- Anaconda: Popular, open-source Python distribution used for data science, machine learning, and AI to simplify package management and environment deployment.

### Get Started

1. Clone the Repository

   ```powershell
   git clone https://github.com/w-obi/ImageClassifier.git
   ```

3. Install dependencies

   ```bash
   pip install -r requirements.txt
   ```
